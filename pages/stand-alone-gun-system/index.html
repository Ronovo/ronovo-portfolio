Stand Alone Gun System

A simple, text-based weapons system in Python. The gunsystem library can be imported into other games, and the repo includes a range demo you can play in the browser or the terminal.

What it does

  • Hit calculation

    Dummy size, damage drop off, bullet drop, muzzle spray and critical chance, worked out from target distance and gun type.

  • Armory

    A menu to look over every gun you have.

  • Gun range

    Test any gun at every listed range, with bulk firing options per gun and a count of the dummies you've destroyed this session.

  • Balance reports

    One report per weapon in /Balance Reports: 15 full magazines at each dummy type, every range and each firing mode (Single, 3 Round, Auto).

Run it

Requires Python 3.10 or newer (this build used 3.13.2). Download the project through Git or as a file, open a terminal in its folder, then:

pip install flask
python -m webapp        # then open http://127.0.0.1:5000

Menus can be clicked or driven from the keyboard: number keys pick an item, Esc goes back. For the terminal version run python ./main.py (or python -m demo) instead.

With Docker 
docker build -t gunsystem-web .
docker run -d --name gunsystem-web -p 8000:8000 gunsystem-web

Open http://127.0.0.1:8000. Set -e GUNSYSTEM_SECRET_KEY=<random string> to keep range sessions valid across restarts, and add -v "${PWD}/Balance Reports:/app/Balance Reports" to keep the balance reports on your machine.

Log in with a portfolio account

The range and destroyed count are kept in the browser for 31 days. With PORTFOLIO_SSO_URL and PORTFOLIO_SSO_PUBLIC_KEY set, the top bar offers to log in with a portfolio account, and while logged in that progress is also kept for the account in DATA_DIR (/app/data in the container, so add a volume there). Logging in on another browser takes whichever copy is newer.

Needs pip install pyjwt[crypto] as well as Flask.

Using it as a library 
from gunsystem import Catalog, Target, resolve_shot

gun = Catalog.create("M1911")
gun.reload()
result = resolve_shot(gun, Target(distance=100, size="m"))

From the repo, or with gunsystem/ on your Python path. result has hit, damage, critical, remaining_ammo and fired (False when the weapon was empty).
