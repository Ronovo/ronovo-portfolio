Stand Alone Gun System

A simple, text-based weapons system built in Python. The gunsystem library can be imported into other games; this repo also includes a range demo you can play in the browser (Flask) or in the terminal.

How to run it What it does

Python 3.10+  ·  Flask  ·  Runs in Docker

V1.5 features

26 guns, with 6 different weapon types.

Hit calculation

Dummy size, damage drop off, "bullet drop", muzzle spray and critical chance.

Armory

A menu to look at all your guns.

Gun range

  • Test out all your guns
  • Bulk fire report to test weapon balancing
  • Dynamic hit calculation based on target distance and gun type
  • A counter of how many dummies you have destroyed in the session
  • Bulk firing options per gun

Balance reports

Creates a report per weapon in /Balance Reports. Each report includes stats for 15 full magazines shot at each type of dummy, every range listed in the Range menu, and each firing mode (Single, 3 Round, Auto).

Run it

Set up

  1. Install Python 3.10 or newer (this build used 3.13.2). Get Python here and run the installer.
  2. Download the project, through Git or a file download.
  3. Go to the project in PowerShell or Command Prompt: cd (drive)/(File Location)/standalonegunsystem

Web version

  1. Install Flask once: pip install flask
  2. Run python -m webapp
  3. Open http://127.0.0.1:5000 in your browser.

Menus can be clicked or driven from the keyboard: number keys pick an item, Esc goes back.

Web version in Docker

docker build -t gunsystem-web .
docker run -d --name gunsystem-web -p 8000:8000 gunsystem-web

Open http://127.0.0.1:8000. Set -e GUNSYSTEM_SECRET_KEY=<random string> to keep range sessions valid across container restarts. Balance text reports are saved inside the container; add -v "${PWD}/Balance Reports:/app/Balance Reports" to keep them on your machine.

Log in with a portfolio account

  • The range and destroyed count are kept in the browser for 31 days.
  • With PORTFOLIO_SSO_URL (the portfolio's address) and PORTFOLIO_SSO_PUBLIC_KEY (printed by the portfolio's python sso.py) set, the top bar offers to log in with a portfolio account. It reads Log in as and the portfolio username when this browser is logged in to the portfolio.
  • While logged in, that progress is also kept for the portfolio account in DATA_DIR (/app/data in the container, so add a volume there), and logging in on another browser takes whichever copy is newer.
  • Needs pip install pyjwt[crypto] as well as Flask.

Terminal version

Run python ./main.py (or python -m demo). The game starts in your terminal window.

Using it as a library

From the repo (or with gunsystem/ on your Python path):

from gunsystem import Catalog, Target, resolve_shot

gun = Catalog.create("M1911")
gun.reload()
result = resolve_shot(gun, Target(distance=100, size="m"))

result has hit, damage, critical, remaining_ammo, and fired (False when the weapon was empty).
