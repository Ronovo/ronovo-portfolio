Stand Alone Gun System

A simple weapons system in Python. The gunsystem library can be imported into other games, and the repo includes a range demo you can play in the browser.

What it does

  • Hit calculation

    Dummy size, damage drop off, bullet drop, muzzle spray and critical chance, worked out from target distance and gun type. Spray control and critical chance per class, damage that varies per hit, shotgun pellets, cover and moving targets, and an exact hit chance for any shot.

  • Armory

    A menu to look over every gun, with its hit chance and a chart of the damage a hit does at each distance.

  • Gun range

    Test any gun at every listed range in Live fire: hits, misses and criticals land on the dummy as they happen, and reloads take the gun's reload time. Forms mode works with JavaScript off. A counter tracks the dummies you've destroyed, and Bulk Fire runs up to 1000 shots per gun.

  • Balance reports

    15 full magazines at each dummy type, every range and each firing mode (Single, 3 Round, Auto). With portfolio login set up, running one needs a portfolio login, only one runs at a time, and each account sees its own latest results.

How a shot is resolved
  1. A target past the gun's max range is always a miss.
  2. Roll 1-100. A 1 or 2 always hits and a 99 or 100 always misses.
  3. Full auto and bursts multiply the roll as a string goes on (muzzle spray), scaled by each class's spray control.
  4. The dummy's size scales it (x1.1 small, x0.9 large).
  5. Distance adds to it in 50 m bands past the gun's base range and takes off inside it. Snipers do worse up close.
  6. Cover adds +10 (light) or +25 (heavy), and a moving target adds +10.
  7. The shot hits when the result is at or below the gun's accuracy. A shotgun rolls once per pellet and hits when any pellet lands.
  8. Damage is full out to the base range, then falls to 25 at max range. Every hit rolls 85-115% of it.
  9. Each class has its own critical chance, from 10% for snipers to 1% for SMGs and LMGs. A critical does x3 damage 80% of the time, x2 the rest.

On full auto, a trigger pull fires one second of the gun's rate of fire. That is what bulk fire and balance reports use.

Run it

Requires Python 3.10 or newer (the Docker image runs 3.12). Download the project through Git or as a file, open a terminal in its folder, then:

pip install -e ".[web]"
python -m webapp        # then open http://127.0.0.1:5000

Menus can be clicked or driven from the keyboard: number keys pick an item, Esc goes back. The top bar picks a theme: Range, Cyberpunk, Dark or Light. The range opens in Live fire; Forms switches to plain page reloads. The browser remembers both.

With Docker 
docker build -t gunsystem-web .
docker run -d --name gunsystem-web -p 8000:8000 gunsystem-web

Open http://127.0.0.1:8000. Set -e GUNSYSTEM_SECRET_KEY=<random string> to keep range sessions valid across restarts.

On every start the container pulls the latest commit on main over the code in the image, so a pushed commit goes live on the next restart. If GitHub can't be reached it starts on the code it has. -e REPO_URL= runs exactly what is in the image, and REPO_BRANCH picks another branch.

Log in with a portfolio account

The range and destroyed count are kept in the browser for 31 days. With PORTFOLIO_SSO_URL and PORTFOLIO_SSO_PUBLIC_KEY set, the top bar offers to log in with a portfolio account, and while logged in that progress is also kept for the account in DATA_DIR (data in the folder you run from, /app/data in the container, so add a volume there). Logging in on another browser takes whichever range is newer and the higher destroyed count.

When a different account logs in on the same browser, the last account's progress stays with it. Range played logged out joins whichever account logs in next.

The web extras (pip install -e ".[web]") include Flask, PyJWT and ronovo-portfolio-auth.

Using it as a library 
from gunsystem import Catalog, Target, resolve_shot

gun = Catalog.create("M1911")
gun.reload()
result = resolve_shot(gun, Target(distance=100, size="m"))

From the repo, or with gunsystem/ on your Python path. result has hit, damage, critical, pellets_hit (1 for anything but a shotgun), remaining_ammo and fired (False when the weapon was empty). Target also takes cover ("none", "light" or "heavy") and moving. hit_chance(gun, target) gives the odds before you fire.
