TTRPG

A browser table for tabletop players

Dice, playing card and tarot decks, a notepad and a Jenga tower in one page. It is a static site with no server code; everything it keeps is saved in your browser.

The tools

The Tools tab holds the dice, the notepad and the cards. Jenga has a tab of its own.

Dice Roller

Roll 1 to 10 of a d4, d6, d8, d10, d12, d20 or d100. Animate throws them across a 3D table instead, in one of 26 dice sets from Basic, Premium and Weird.

Card Drawer

Build a stack from any number of playing card decks, with or without jokers, or tarot decks. Draw, shuffle, discard, shuffle the discard back in, and add another deck at any time.

Tarot

Tarot cards come up reversed half the time, and the Major and Minor Arcana can be split into two piles.

Notepad

Session notes, NPC names and loot, kept in the browser between visits.

Jenga

Pull blocks from a tower. Each pull makes it more likely to fall, at Less Tense, Normal or More Tense, and the tower shows how it is holding up: Solid, Wobbly, Teetering or Doomed.

Styles and saving

Ten styles

Tabletop, Parchment, Polished Dark, Casino, Eldritch, Neon, Dossier, Slasher, Field Kit and Forest, picked from Style in the header.

Saved in your browser

The notes, the Jenga tower, the style and the dice set are kept in the browser's localStorage. There are no accounts, so they are separate for each browser and each address the site is served from.

Run it

Uses Node 24, the version the Dockerfile builds with.

From source

npm install
npm run dev       # http://localhost:5173 with live reload
npm run build     # writes the site to dist/
npm run preview   # serves dist/

With Docker

docker build -t ttrpg-player-toolkit .
docker run -d -p 8080:80 ttrpg-player-toolkit

The Dockerfile builds the site and serves it with nginx on port 80. It keeps no data, so it needs no volume.
