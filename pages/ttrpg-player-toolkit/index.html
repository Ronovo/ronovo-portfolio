TTRPG

A browser table for tabletop players

Dice, playing card and tarot decks, a notepad and a Jenga tower in one page. A React site served by a small Flask server, which adds portfolio login for uploading your own dice and a character sheet. Everything else is saved in your browser.

The tools

Each tool has its own tab. Home starts with the dice roller and notepad side by side and the card drawer below. Edit layout turns Home into a canvas you arrange into your own table: add, drag, resize or remove tools. The layout is kept in this browser.

  • Dice Roller

    Roll 1 to 10 of a d4, d6, d8, d10, d12, d20 or d100. Animate throws them in 3D in one of 51 dice sets from Basic, Premium and Weird. Star sets into Favorites. On the Dice Roller tab they land on a roll mat (felt, velvet, leather, wood, stone or your own picture, with an optional rim), and Tower adds one of nine dice towers.

  • Card Drawer

    Build a stack from any number of playing card decks, with or without jokers, or tarot decks. Draw, shuffle, discard and shuffle the discard back in. Each pile shows its deck face down; click it to draw. Card backs follow the page style, or use a picture you upload.

  • Tarot

    Cards come up reversed half the time, and the Major and Minor Arcana can be split into two piles.

  • My Dice

    With portfolio login on, a logged-in player can upload their own dice set: a name, a .glb from Blender with the seven dice shapes, and an optional screenshot. 12 MB at most, ten sets per account, each account sees only its own.

  • Notepad

    Session notes, NPC names and loot, kept in the browser between visits.

  • Character Sheet

    With portfolio login on, upload one PDF character sheet and read it in a pdf.js viewer with zoom and fit-to-width. Fillable fields save to your portfolio account as you type, and Download saves the filled-in PDF. 20 MB at most.

  • Jenga

    Pull blocks from a tower at Less Tense, Normal or More Tense. Each pull makes a fall more likely, and the tower reads Solid, Wobbly, Teetering or Doomed.

Styles and saving

Ten styles
Tabletop, Parchment, Polished Dark, Casino, Eldritch, Neon, Dossier, Slasher, Field Kit and Forest, picked from Style in the header.
Saved in your browser
The notes, the Jenga tower, the style, the dice set, the favorites, the roll mat, the tower and the card back are kept in localStorage, so they are separate for each browser and each address the site is served from. Uploaded dice sets and the character sheet are kept by the server.

Run it

Uses Node 24 and Python 3.12, the versions the Dockerfile builds with.

npm install
npm run dev       # http://localhost:5173 with live reload
npm run build     # writes the site to dist/
npm run preview   # serves dist/
With Docker 
docker build -t ttrpg-player-toolkit .
docker run -d -p 8080:8080 -v ttrpg-toolkit-data:/app/data ttrpg-player-toolkit

The Dockerfile builds the site and serves everything with gunicorn on port 8080. Uploaded dice live in /app/data, so give it a volume there. docker compose up -d --build does the same on 127.0.0.1:8090.

Server and tests 
npm test          # the Vitest tests in tests/
npm run coverage  # the same, with an HTML report in coverage/js
pip install -e .[test]
flask --app server run --port 8080

npm run dev sends /api and /sso to it on port 8080.

PORTFOLIO_SSO_URL, PORTFOLIO_SSO_PUBLIC_KEY
The portfolio to log in through and the key its login tokens are checked with. Login and uploads are on only when both are set.
TOOLKIT_SECRET_KEY
Signs the session cookie. Without it each start makes a new key and logs everyone out.
SECURE_COOKIES
1 marks the session cookie HTTPS-only.
DATA_DIR
Where uploaded sets and their database go. data/ by default, /app/data in the image.
Project layout 
src/App.jsx              Header, tabs and style picker
src/components/          Home and its canvas windows, the tools, and shared controls
src/lib/                 Dice, decks, card piles, Jenga odds, random numbers and image uploads
src/dice3d/              3D: three.js window table and roll mat, cannon-es physics, towers, dice.json, props.json
src/hooks/               useStoredState (a value kept in localStorage), useDiceRoll (shared roller state) and
                         useAccount (the portfolio login and the account's uploaded sets)
server/                  The Flask server: the site, portfolio login, dice uploads, the model check, the
                         character sheet and their shared storage
src/sheet/               The PDF reader for the character sheet, on pdf.js
public/dice/             Dice models, one .glb per set, and a thumbnail of each set in thumbs/
public/mats/             Roll mat surfaces and the rim models
public/towers/           Dice tower models, and a thumbnail of each in thumbs/
public/cards/tarot/      Tarot card images
tests/                   Vitest tests for src/, and tests/python/ for server/

The dice, mats, rims, towers, dice.json and props.json are built in Blender by the blender-asset-builder repository.
