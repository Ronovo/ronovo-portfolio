Space Station Explorer Online

A text-based exploration game set on a space station, played in the browser. A Flask web app with accounts, where each account owns one character whose progress is saved on the server.

Core features

  • Accounts

    Register with a username, a password and a security question; each account owns exactly one character, saved after every action. Forgot password? resets with the answer; five wrong answers lock resets for 15 minutes.

  • Jobs

    Create a character with a job from Staff Assistant to Captain, each with its own access and starting credits.

  • The station

    A hollow-square ring of hallways with Quarters at the junction and Bridge, MedBay, Security, Engineering Bay, Bar and Botany Lab branching off, with random events on the way.

  • Inventory

    Carry items, store them in your quarters locker, and examine, read, drop or drink them.

  • Health

    Limb damage plus burns, poison and oxygen, treated in MedBay.

  • Crew

    Start alongside procedurally staffed NPC department heads and assistants. Deleting your character erases its progress so you can roll a new one.

Station systems

Power
Battery levels, power allocation to life support, lighting, security and communications, solar charging, and emergency modes. The Engineering panel is for Engineers and the Captain.
Life support
Oxygen follows power allocation. Underpowered life support damages the player and crew, with an emergency revive if it reaches critical levels.
Medical
Paid treatment and assessments in MedBay; Doctors treat themselves for free and monitor crew vitals.
Security
Access control for restricted areas, door locking for authorised staff, and a crew manifest for Security.
Stock market
A live simulation traded from your quarters computer, with price history, portfolio and profit tracking, filters and a transaction history.
Bar
Order from the menu, mix drinks as the Bartender, and watch the alcohol tally on your character sheet.
Botany
Collect seeds at the botanist station and plant across several planters, with status monitoring and Botanist-only access.
Bridge and personnel
Talk to the ship's leadership, a crew manifest and NPC job assignment for the Head of Personnel, a public terminal for job-change requests, and Bridge door control for the Captain and HoP.
Engineering
A fabricator for tools, books and components, and the full power panel for authorised staff.

Tips
  • Monitor your health and seek treatment in MedBay when needed.
  • Keep track of power levels and oxygen status from Engineering.
  • Use the stock market on your quarters computer to earn additional credits.
  • Explore all rooms to discover features, items and job-specific stations.
  • Progress saves automatically; Save and Exit returns you to your account page.

Run it

Requires Python 3.10 or newer. Flask's built-in server is fine on your own machine or a LAN.

python -m venv .venv
.venv\Scripts\activate          # Windows; use `source .venv/bin/activate` elsewhere
pip install -r requirements.txt
python run_server.py

Open http://127.0.0.1:5000, register an account, and create your character. Accounts and characters live in instance/space_online.sqlite3: back that folder up to keep your players, delete it to start fresh.

Settings
HOST
Interface to bind, default 127.0.0.1. Use 0.0.0.0 so other machines on your network can connect.
PORT
Port to listen on, default 5000.
SPACE_ONLINE_SECRET_KEY
Session signing key. If unset, one is generated once into instance/secret_key.
With Docker 
docker build -t space-station-explorer-online .
docker run -d -p 5000:5000 -v space-online-data:/app/instance space-station-explorer-online

The Dockerfile runs the game under gunicorn on port 5000, with the data in a volume at /app/instance. Set SPACE_ONLINE_SECRET_KEY with -e so logins survive the key file being lost.

Log in with a portfolio account

With PORTFOLIO_SSO_URL and PORTFOLIO_SSO_PUBLIC_KEY set, the login page offers to log in with a portfolio account, and reads Log In as plus the portfolio username when this browser is logged in there. The first such login links an account you already have, or makes a new one named after the portfolio username.

A new account has no password of its own, so the portfolio is the only way into it. Without those two settings the app runs on its own.

Tests and project layout 
pip install -r requirements-dev.txt
python -m pytest

The tests cover accounts, character creation, playing and saving, and the core game rules: jobs, door access, inventory.

run_server.py            Starts the game with Flask's built-in server
space_online/webapp/     Flask app: routes, accounts, SQLite storage, templates, static files
space_online/game/       The game itself: station map, rooms, items, crew, jobs, power, market
tests/                   pytest suite
instance/                Created on first run: the database and secret key (not committed)
