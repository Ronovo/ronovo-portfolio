What it does

One responsive app for keeping track of a character and the market, on desktop or phone.

Character
Any player's Jagex hiscores: combat level, total level and XP, skill levels, XP and ranks, boss kill counts and minigame scores.
Progress from RuneLite
What the hiscores don't show, synced by Ronovo's Sync Tool: quests with type and membership filters, diary tiers by area, combat achievements and points, the collection log obtained and missing, and completed Leagues tasks from the Leagues Tasks plugin.
Grand Exchange
OSRS Wiki market data: 24-hour risers and fallers, price, volume and freshness filters, and item pages with a price history chart, margins and alch values.
Flip Helper
Scans the market for buy-low, sell-high opportunities with after-tax profit, ROI, GP/hr and confidence, plus presets, filters, a per-character watchlist and a calculator for any item.

Prices come from completed trades, not live offers. Always check the in-game GE offer box before committing money.

Plugin sync

Jagex doesn't publish quests, diaries, combat achievements or the collection log. Those tabs fill in when you sync from the Ronovo's Sync Tool RuneLite plugin, pointed at your tracker.

  1. Run the tracker and copy your token with Copy plugin token in the header.
  2. In the Sync Tool's Sync Settings, set Server URL to the tracker's base address, such as http://localhost:4123 (or https:// for anything not on this computer), and paste the API Token.
  3. Log in to OSRS and press a Sync button. The collection log syncs from the Sync button on the in-game Collection Log, and completed Leagues tasks from the Leagues Tasks plugin's Sync Progress button.

Each sync only updates the sections it sends. Leaving a section out never clears what the tracker already has.

Run it

A small Node server you host yourself; there is no shared public instance. Needs Node.js 24 or newer. 

npm ci
npm start

Get the source from the GitHub page (Code → Download ZIP, or clone it), run those in that folder, then open http://localhost:4123. Other devices on your network use http://<computer-address>:4123.

With Docker 
docker build -t osrs-tracker .
docker run -d --name osrs-tracker --restart unless-stopped \
  -p 4123:4123 \
  -e JWT_SECRET=a-long-random-secret -e LAN_MODE=1 \
  -v osrs-tracker-data:/app/data \
  osrs-tracker

Keep the -v volume: it holds every synced character and watchlist, and is lost with the container otherwise. docker logs osrs-tracker shows the LAN token.
