Dead But Dreaming

In his house at R'lyeh dead Cthulhu waits dreaming.

You are an Old One buried deep beneath the earth. You cannot wake, but you can dream, and cultists answer. Every scrap of sanity the world loses flows down to you. Gather enough and you devour the world; then Azathoth spins up a fresh one and the dreaming begins again.

Features

  • Nine Great Old Ones

    Play as one of nine, or name your own.

  • Ten resources

    Cultists to Great Old Ones, each with a manager and five upgrades: speed 2x, 3x and 5x, production 2x and 5x.

  • Five difficulties

    Quick and Easy in 15-20 minutes, Short Dream in about an hour, up to an Eternal run of 60-80 hours.

  • Idle or Clicker Mode

    Chosen per world. In Clicker Mode, tapping a working resource hurries it along.

  • 35 achievements

    Grouped by difficulty, with a timed pair per difficulty and filters for earned and mode.

  • Nine themes and statistics

    A style per Great Old One, and lifetime sanity and worlds devoured by difficulty for accounts.

How to play

  1. Click on resources to start gathering them. In Clicker Mode, keep tapping a working resource to hurry it along.
  2. Hire managers to automate them, and buy upgrades for speed and production.
  3. Buy every upgrade and hire every manager to devour the world.
  4. Keep feeding in Endless Mode, or begin a new world. Your save counts the worlds you've destroyed.
The rules in detail
Managers
Produce automatically, including while the game is closed. A resource you clicked by hand finishes its one cycle.
Upgrades
The list shows the next speed and the next production upgrade of each unlocked resource.
Difficulty
Scales the costs of every tier past the first, so the first cultists cost the same everywhere.
Taps
One tap is worth 5% of a cycle, at most about twelve a second per resource, so tapping matters early and fades once speed upgrades arrive.
Saves
Kept in your browser and written continuously; the game catches up on the time it was closed.
How it works under the hood

The game logic is Python. The browser keeps the save and shows the game; it doesn't run any of the rules.

The browser stores each save as JSON in localStorage, including when it was last saved. About four times a second, and whenever you click, it sends the save and your clicks to POST /api/play. Flask rebuilds the Game from the save, advances it by the time since last_saved, applies the clicks, and sends back the new save plus what to display. Time spent closed is covered by that same step.

Accounts

Logging in is optional. Without it, everything stays in the browser. With it, progress follows you to any browser you log in from, and the Statistics page opens.

Merging
Logging in merges this browser's saves, achievements and devours with the account's. Two copies of one world keep the one further along, the newer breaking a tie. A different world under a name the account holds replaces it when it began later. Each devour counts once. An account keeps up to 50 worlds.
Backups
Saves are copied to the account whenever progress changes, every 30 seconds, and when you leave the page.
Deleting
Deleting a world deletes it from the account too, and other browsers drop their copies on their next sync.
Shared browsers
Logging out keeps this browser's copy. Saves that came from one account are cleared when a different account logs in, and stay in their own account.
Lockouts
Five wrong passwords in a row lock a username's logins for a minute. A password reset logs the account out of every other browser.
Reset
Creating an account asks for a security question. Forgot Password resets with its answer; five wrong answers lock resets for 15 minutes.
Log in with a portfolio account

With PORTFOLIO_SSO_URL and PORTFOLIO_SSO_PUBLIC_KEY set, the top bar offers to log in with a portfolio account, and reads Log In as plus the portfolio username when this browser is logged in there. The first such login links a Dead But Dreaming account you already have, or makes a new one named after the portfolio username.

A new account has no password of its own, so the portfolio is the only way into it. Without those two settings the app runs on its own. The README has the rest.

Security caveats
Unencrypted
Unless the site is served over HTTPS, passwords cross the network in plain text. The login screen warns whenever the page isn't on HTTPS. Use a password you don't use anywhere else.
Signed saves
The server signs every save and achievement record it sends and refuses one that was edited. A refused save stops the game with a message instead of loading.
Security answers
Anyone who can guess your answer can reset your password, so pick one that isn't public.

Run it

Requires Python 3.10+. Then open http://localhost:5000.

pip install -r requirements.txt
python Game_Logic/webapp.py
With Docker 
docker compose up -d --build

Then open http://localhost:8005. The local compose file runs your working copy as-is, and keeps accounts in the dead-but-dreaming-data volume.

Settings
DEAD_BUT_DREAMING_SECRET_KEY
Signs logins, saves and records. Without it a key is generated once into the data folder, so set it when that folder isn't kept between runs.
DATA_DIR
Folder for the accounts database and the generated key. ./data, or /app/data in the image.
SECURE_COOKIES
1 marks the login cookie Secure, for a site served over HTTPS.
REPO_URL
Set by the image to this repository: the container pulls main every time it starts and reinstalls requirements when needed. Empty runs exactly what is in the image.
Tests and coverage 
pip install -r requirements-dev.txt
pytest
npm install
npm test

The game rules are covered by pytest and the display script by Vitest, both held at 100%. The Docker image builds both coverage reports and serves them at /coverage/.
