What it does

Jagex's hiscores don't show which quests you've done, your diaries, your combat achievements or your collection log. This plugin reads them in RuneLite and sends them to your tracker.

  • Section by section

    Sync everything once, then keep tasks, quests, diaries or combat achievements up to date on their own. The tracker keeps whatever a sync leaves out.

  • Collection log

    A Sync button on the in-game Collection Log captures every slot. The last capture is kept per character, so a full sync can include it later.

  • Works with Leagues Tasks

    Sends the tasks you completed in the Leagues Tasks plugin, and powers that plugin's Sync Progress button.

  • One direction only

    It posts to the tracker and only reads back whether that worked. Nothing from the tracker changes anything in your client.

  • Careful with your token

    Plain http:// is refused for anything but localhost, redirects are not followed, and the token never appears in a log.

  • Per character

    Each sync is for the character you're logged in as, so an alt's progress never lands on your main.

What a sync sends

Sync is off until you set a server URL and token. There is no shared or default server. When you press a Sync button, the plugin sends only:

  • Your character name and account hash
  • Quest completion states
  • Your collection log, only once captured from the in-game interface
  • Achievement diary progress
  • Combat achievement progress
  • Your list of completed Leagues tasks, from the Leagues Tasks plugin

Install

Until the plugin is on the RuneLite Plugin Hub, you run it from source: a small Gradle command builds it and opens a RuneLite client with the plugin already loaded, on its own or together with Leagues Tasks.

Step-by-step: run it in RuneLite

It needs your own Personal RuneScape Tracker instance, a self-hosted character log and Grand Exchange tool. See the README for setup.
