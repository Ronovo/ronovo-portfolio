What it does

A web app for the tables a gamemaster rolls on mid-session, kept in one place instead of scattered across books and notes.

  • Game systems

    Group oracles and flows by the game they belong to.

  • Oracle builder

    Dice oracles use any die from d4 to d100, or several dice such as 2d6. Card oracles use a playing-card or tarot deck.

  • Rolling and drawing

    Roll a table, or draw from a deck shuffled for your session. Which cards are left is per person and per sitting.

  • Flows

    Chain oracles together and run them a step at a time, with questions and branches along the way.

  • Export and import

    Download every game system, oracle and flow as one versioned JSON file, and read it back in elsewhere.

  • Color themes

    Pick a theme from the dropdown in the top right.

Flows

A flow is an ordered list of steps. Running it works through one step at a time; any outcome can branch to another step or end the run early, so a flow can fork, skip ahead or loop back.

StepWhat it does
RollRolls the oracle it names. Each outcome can also pick a table for a later step.
ChoiceAsks a question with a dropdown of options you write. An option can name an oracle.
TextAsks a question and takes a typed answer.
RollChosenRolls whichever oracle an earlier step picked.

A dependent chain, roll A then roll whatever A landed on, is a Roll whose outcomes each pick a table, followed by a RollChosen. A run stops after 200 steps, so a backwards branch can't loop forever.

Run it

There's no database server to install; the whole toolbox lives in one SQLite file. It is meant for a machine on your own network, shared with the people at your table. There are no permissions yet, so it isn't set up to be exposed to the internet. 

docker compose up -d

Open http://localhost:9000, or http://<your-machine's-ip>:9000 from elsewhere on the network. docker compose down stops it; your data stays in its volume.

With the .NET SDK instead

Install the .NET 10 SDK, run dotnet run in the project folder, and open http://localhost:9000. This way only your own machine can reach it.
