Your random tables, rolled for you

Build dice and card oracles for any game system, chain them into flows that ask questions and branch, and take the whole set with you as one JSON file.

What it does

A web app for the tables a gamemaster rolls on mid-session, kept in one place instead of scattered across books and notes.

Game systems

Group oracles and flows by the game they belong to.

Oracle builder

Dice oracles use any die from d4 to d100, or several dice such as 2d6. Card oracles use a full playing-card deck or a tarot deck.

Rolling and drawing

Roll a dice table, or draw from a deck shuffled for your session. Which cards are left is per person and per sitting.

Flows

Chain oracles together and run them a step at a time, with questions and branches along the way.

Export and import

Download every game system, oracle and flow as a single versioned JSON file, and read one back in on another instance.

Color themes

Pick a theme from the dropdown in the top right.

Flows

A flow is an ordered list of steps. Running it works through one step at a time; any outcome can branch to another step or end the run early, so a flow can fork, skip ahead or loop back.

StepWhat it does
Roll Rolls the oracle it names. Each outcome can also pick a table for a later step.
Choice Asks a question with a dropdown of options you write. An option can name an oracle.
Text Asks a question and takes a typed answer.
RollChosen Rolls whichever oracle an earlier step picked.

A dependent chain - roll A, then roll whatever A landed on - is two steps: a Roll whose outcomes each pick a table, then a RollChosen. A run stops after 200 steps, so a branch that points backwards can't loop forever.

Run it

There's no database server to install. The whole toolbox lives in one SQLite file.

With Docker

docker compose up -d

Open http://localhost:9000. docker compose down stops it, and your data stays in its volume. Other people on your network can reach it at http://<your-machine's-ip>:9000.

With the .NET SDK

  1. Install the .NET 10 SDK.
  2. In the project folder, run dotnet run.
  3. Open http://localhost:9000. This way only your own machine can reach it.

Who it's for

A machine on your own network, shared with the people at your table. There are no permissions yet: everyone who can reach it can edit everything, so it isn't set up to be exposed to the internet.

Built with ASP.NET Core MVC, Entity Framework Core and SQLite, Bootstrap and jQuery.
