Every Leagues task, in your RuneLite sidebar

Browse and randomise tasks from past Old School RuneScape Leagues events, filter them the way you want, and track what you have finished — with optional progress sync to a tracker you run yourself.

What it does

One sidebar panel that turns a scattered pile of Leagues tasks into something you can actually work through.

One unified list

Over 2,200 tasks drawn from four past Leagues events, merged so a task that appeared in more than one event is a single row.

Filter, then pick

Narrow by region, difficulty, and activity type, then roll a random task that fits — or browse the full filtered list.

Save and check off

Keep one saved task per difficulty tier and mark tasks complete against a running background log.

Autocomplete

Detects tasks it can confirm from your account — quests, skill levels, achievement diaries, combat achievements, boss kills, clue counts. It shows a preview first; nothing is written until you confirm.

Optional progress sync

Send your progress to a Personal RuneScape Tracker instance you host yourself. Opt-in, one direction only, and only when you press a Sync button.

Per character

Completions and saved tasks are scoped to each character, so an alt's progress never overwrites your main's.

What syncing sends

Sync is off until you set a server URL and token. When you press a Sync button, the plugin sends only:

  • Your character name and account hash
  • Quest completion states
  • Your collection log (when the in-game interface is open)
  • Achievement diary progress
  • Combat achievement progress
  • Your list of completed Leagues tasks

The connection is one-way: the plugin posts to the server URL you configure and never reads anything back. Nothing is sent unless you have entered a URL and token and pressed a Sync button. There is no shared or default server.

Install

The plugin is not on the RuneLite Plugin Hub yet. Until it is, you run it from source: a small Gradle command builds it and opens a RuneLite client with the plugin already loaded.

Step-by-step: run it in RuneLite

Once the plugin is on the Plugin Hub, install it from there instead: wrench (Configuration) → Plugin Hub → search Leagues Tasks. This page will be updated when it is.

Syncing is optional and needs your own Personal RuneScape Tracker instance — a self-hosted character log and Grand Exchange tool. See the README for setup.
