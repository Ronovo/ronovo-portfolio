What it does

One sidebar panel that turns a scattered pile of Leagues tasks into something you can work through.

  • One unified list

    Over 2,200 tasks from four past Leagues events, merged so a task that appeared in more than one event is a single row.

  • Filter, then pick

    Narrow by region, difficulty and activity type, then roll a random task that fits, or browse the filtered list.

  • Save and check off

    Keep one saved task per difficulty tier and mark tasks complete against a running log.

  • Autocomplete

    Detects tasks it can confirm from your account: quests, skill levels, diaries, combat achievements, boss kills, clue counts. It previews first and writes nothing until you confirm.

  • Optional progress sync

    Install Ronovo's Sync Tool alongside it to send progress to a tracker you host. Without it, this plugin sends nothing.

  • Per character

    Completions and saved tasks are scoped to each character, so an alt never overwrites your main.

Data & sync

Your progress is saved locally through RuneLite's own config. This plugin has no server settings and sends nothing anywhere.

Syncing
Lives in a separate plugin, Ronovo's Sync Tool, which reads your completed tasks from this plugin's saved data and sends them, with your quests, diaries, combat achievements and collection log, to your tracker.
The button
With the Sync Tool on, Sync Progress on the start menu asks it to send your completed tasks. Without it, the button reads Install Ronovo's Sync Tool and explains how.

Install

Until the plugin is on the RuneLite Plugin Hub, you run it from source: a small Gradle command builds it and opens a RuneLite client with the plugin already loaded.

Step-by-step: run it in RuneLite

Once it is on the Plugin Hub: wrench (Configuration) → Plugin Hub → search Leagues Tasks. Syncing is optional and needs Ronovo's Sync Tool plus your own Personal RuneScape Tracker; see the Sync Tool's page for setup.
