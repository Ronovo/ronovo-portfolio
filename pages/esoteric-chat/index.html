Using the chat

Pick a language from the dropdown, type code, and press Enter. Shift+Enter adds a new line.

  • Try example

    Lists sample programs for the selected language and fills in the one you pick.

  • Commands

    Shows the language's valid characters.

  • Language Explained

    Opens the language's esolangs.org page.

  • $ commands

    Messages starting with $ run whatever language is selected, except under Kallisti, which repeats every message back exactly.

  • Exact input

    Everything after the command name and one space or new line is passed on exactly as typed.

Differences from the Discord bot
Brainfart
Supports nested loops, uses 8-bit wrapping cells and stops after 1,000,000 steps.
HQ9+
Accepts upper- and lowercase commands; the + accumulator is kept in memory per server process instead of in index.json.
Kallisti
Reverses each message, swaps its case and shifts every letter 5 places, then undoes all three, so the message still comes back exactly as sent.
$close
Dropped, because there is no bot connection to close.

Run it

Requires Python 3.10 or newer. Flask's built-in server is fine on your own machine or a LAN; --host 0.0.0.0 lets other machines connect.

python -m venv .venv
.venv\Scripts\activate           # Windows; use `source .venv/bin/activate` elsewhere
pip install -r requirements.txt
python -m esoteric_chat.server   # http://127.0.0.1:5000  (--host, --port, --debug)
With Docker 
docker build -t esoteric-chat .
docker run -d -p 5000:5000 esoteric-chat

The Dockerfile runs the app under gunicorn on port 5000. It keeps no data, so it needs no volume.

Log in with a portfolio account

With PORTFOLIO_SSO_URL and PORTFOLIO_SSO_PUBLIC_KEY set, the header offers to log in with a portfolio account and shows who is logged in, reading Log in as plus the portfolio username when this browser is logged in there.

Nothing is saved to the account yet. Set ESOTERIC_CHAT_SECRET_KEY to keep logins across restarts.

API
GET /api/languages
{"languages": [{"id", "name", "examples", "intro", "info_url", "help"}]} in picker order; the first is selected on load. examples is a list of {"label", "code"}, intro is shown when the language is selected (or null), and help is the card the Commands button shows.
POST /api/chat
Takes {"message": "...", "language": "bf"} and returns {"replies": [...]}. Each reply is {"type": "text" | "error", "text"} or {"type": "help", "title", "color", "fields": [{"name", "value"}]}.
