A chat that runs esoteric languages

A Flask chat web app that interprets esoteric languages. It is a port of my esoteric-bot Discord bot.

How to run it How to use it

Python 3.10+  ·  Flask  ·  Runs in Docker

Using the chat

Pick a language from the dropdown, type code, and press Enter (Shift+Enter adds a new line).

Try example

Lists sample programs for the selected language and fills in the one you pick.

Commands

Shows the language's valid characters.

Language Explained

Opens the language's esolangs.org page.

$ commands

Messages starting with $ are commands and run regardless of the selected language, except Kallisti: with Kallisti selected, every message is repeated back exactly, $ included.

Exact input

Everything after the command name and one space (or new line) is passed on exactly as typed.

Commands

CommandDescription
$pingReturns pong in Brainfart
$hi / $helloReturns hello in Brainfart
$fivecommand <code>5command
$bf <code>Brainfart
$deadsimple <code>DeadSimple
$hatemath <code>Hatemath
$hq9plus <code>HQ9+
$kallisti <code>Kallisti
$unnecessary <code>Unnecessary (an empty program or # is a successful call)

Differences from the Discord bot

  • Brainfart supports nested loops, uses 8-bit wrapping cells and stops after 1,000,000 steps.
  • HQ9+ accepts upper- and lowercase commands, and the + accumulator is kept in memory per server process instead of in index.json.
  • $close was dropped because there is no bot connection to close.
  • Kallisti reverses each message, swaps its upper and lower case and shifts every letter 5 places, then undoes all three, so the message still comes back exactly as sent.

Run it

Requires Python 3.10 or newer.

From source

python -m venv .venv
.venv\Scripts\activate        # Windows; use `source .venv/bin/activate` elsewhere
pip install -r requirements.txt
python -m esoteric_chat.server   # http://127.0.0.1:5000  (--host, --port, --debug)

python -m esoteric_chat.server uses Flask's built-in server, which is fine on your own machine or a LAN. Use --host 0.0.0.0 so other machines can connect.

With Docker

docker build -t esoteric-chat .
docker run -d -p 5000:5000 esoteric-chat

The Dockerfile runs the app under gunicorn on port 5000. It keeps no data, so it needs no volume.

Log in with a portfolio account

With PORTFOLIO_SSO_URL (the portfolio's address) and PORTFOLIO_SSO_PUBLIC_KEY (printed by the portfolio's python sso.py) set, the header offers to log in with a portfolio account and shows who is logged in. It reads Log in as and the portfolio username when this browser is logged in to the portfolio.

Nothing is saved to the account yet. Set ESOTERIC_CHAT_SECRET_KEY to keep logins across restarts.

For developers

API

  • GET /api/languages returns {"languages": [{"id", "name", "examples", "intro", "info_url", "help"}]} in picker order; the first is selected on load. examples is a list of {"label", "code"}, intro is shown when the language is selected (or null), and help is the card the Commands button shows.
  • POST /api/chat with {"message": "...", "language": "bf"} returns {"replies": [...]}. Each reply is {"type": "text" | "error", "text"} or {"type": "help", "title", "color", "fields": [{"name", "value"}]}.

Tests

pip install -r requirements-dev.txt
python -m pytest

The tests cover every interpreter, the $ commands, and the HTTP API.
