Using the chat

Pick a language from the dropdown, type code, and press Enter. Shift+Enter adds a new line.

  • Try example

    Lists sample programs for the selected language and fills in the one you pick.

  • Commands

    Shows the language's valid characters.

  • Language Explained

    Opens the language's esolangs.org page.

  • Every message runs

    Each message runs in the selected language. Kallisti repeats every message back exactly: first as it looked once scrambled, under a "Scrambled:" line, then the exact echo.

  • New chat

    Opens another chat in the sidebar. Each chat keeps its own messages, language and unsent draft. Close one with its × button; the last one stays open.

  • Clear Chat

    Asks first, then empties the open chat's messages. Its name, language and draft stay.

  • Themes

    Esoteric (the default, follows the system's light or dark setting), Cyberpunk, Dark, Light, Punch Card, Chalkboard and Baby Girl.

Limits: 64 KB a request, 65,536 characters of replies per message, a 30,000-cell Brainfart tape and 1,000,000 steps. An account can save 50 chats, and a chat keeps its newest 1,000 messages. The HQ9+ + accumulator is shared by everyone on the server.

Differences from the Discord bot
Brainfart
Supports nested loops, uses 8-bit wrapping cells and stops after 1,000,000 steps.
HQ9+
Accepts upper- and lowercase commands; the + accumulator is kept in memory per server process instead of in index.json, and the 10-reply limit is gone (the output cap covers it).
Kallisti
Scrambles each message with 1 to 13 random passes (reverse, swap case, shift letters, rotate, flip blocks, riffle, mirror alphabet, leetspeak, reverse each word, wave case, deal into piles), then undoes them in reverse order, so the message still comes back exactly as sent. The scrambled message is shown first.
$ commands
Gone ($ping, $hi, $hello, $close and one per language). Every message runs in the selected language, and Try example holds the sample programs.

Run it

Requires Python 3.10 or newer. Flask's built-in server is fine on your own machine or a LAN; --host 0.0.0.0 lets other machines connect. Don't add --debug then: its debugger lets anyone who can reach the server run code on it.

python -m venv .venv
.venv\Scripts\activate           # Windows; use `source .venv/bin/activate` elsewhere
pip install -r requirements.txt
python -m esoteric_chat.server   # http://127.0.0.1:5000  (--host, --port, --debug)
With Docker 
docker build -t esoteric-chat .
docker run -d -p 5000:5000 -v esoteric-chat-data:/app/data esoteric-chat

The Dockerfile runs the app under gunicorn on port 5000. Saved chats and the generated session key live in /app/data, so mount a volume there to keep them.

On every start the container runs docker/git-sync.sh, which pulls the latest commit on GitHub main, so a pushed commit goes live on the next restart without rebuilding.

Log in with a portfolio account

With PORTFOLIO_SSO_URL and PORTFOLIO_SSO_PUBLIC_KEY set, the header offers to log in with a portfolio account and shows who is logged in, reading Log in as plus the portfolio username when this browser is logged in there.

Logged in, your chats and theme are saved to the account and come back on any device; logged out, chats last until the page is reloaded and the theme is kept in this browser. Logins last across restarts: the session key is ESOTERIC_CHAT_SECRET_KEY when set, otherwise one is generated once into the data folder.

API
GET /api/languages
{"languages": [{"id", "name", "examples", "intro", "info_url", "help"}]} in picker order; the first is selected on load. examples is a list of {"label", "code"}, intro is shown when the language is selected (every language has one), and help is the card the Commands button shows.
POST /api/chat
Takes {"message": "...", "language": "bf"} and returns {"replies": [...]}. Each reply is {"type": "text" | "error", "text"}. Add "chat_id" and "meta" to also save the message and its replies to that chat; this needs a portfolio login.
Saved chats
GET/POST /api/chats, PATCH/DELETE /api/chats/<id> and DELETE/POST /api/chats/<id>/messages. These need a portfolio login and only reach the account's own chats.
PUT /api/theme
Saves the theme to the logged-in account.
Tests and project layout 
pip install -r requirements-dev.txt
python -m pytest

The tests cover every interpreter, the language examples, the HTTP API, saved chats and portfolio login. The chat page's script has its own Vitest tests: npm install once, then npm test.
