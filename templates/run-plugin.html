1. Install JDK 11

RuneLite builds against Java 11. Install a JDK 11, for example Eclipse Temurin 11, and set JAVA_HOME to it. On Windows, in PowerShell:

$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-11.0.x-hotspot"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"

2. Get the plugin

On the GitHub page, choose Code → Download ZIP and extract it, or clone the repository.

3. Start RuneLite with the plugin

In the plugin's folder, run:

gradlew.bat run

On macOS or Linux, run ./gradlew run instead. Gradle downloads itself the first time, so that run takes a while. It builds the plugin and opens a RuneLite client in developer mode with just this plugin loaded.

To load {{ other.title }} in the same client, get it the same way into a folder named {{ other_folder }} next to this one, then run:

gradlew.bat {{ run_both }}

If that folder isn't there, it prints a warning and starts {{ plugin.title }} on its own.

4. Open the plugin

Log in, then open {{ plugin.title }} from its icon in the sidebar.

Jagex accounts

The developer client can't use the Jagex Launcher's login directly. Follow RuneLite's Using Jagex Accounts guide once: add --insecure-write-credentials under Client arguments in RuneLite (configure), then launch RuneLite through the Jagex Launcher. That saves a login file the developer client then uses. Anyone with that file can log in as you, so never share it.

Why not just copy the plugin into RuneLite?

RuneLite only loads plugins from its sideloaded-plugins folder in developer mode, and a client started from the RuneLite or Jagex launcher never runs in developer mode. A copied plugin is ignored.
